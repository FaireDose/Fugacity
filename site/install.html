Install the CHEPTA skill

The skill teaches your AI assistant to load the CHEPTA workbench, draw phase diagrams and answer property questions with their sources. Install it once; afterwards just ask, for example "Load the CHEPTA workbench" or "Load the CHEPTA workbench with ethanol and water".

Download skill.zip Download contributor-skill.zip (for contributing to the project)

Claude (claude.ai and the desktop app)

Turn on Settings → Capabilities → Code execution and file creation. Then Customize → Skills → + → Create skill → Upload a skill and choose skill.zip. On Team and Enterprise plans an owner first allows skills for the organization.

ChatGPT (Business, Enterprise, Edu and Healthcare workspaces)

Skills → Create → Upload from your computer, choose skill.zip.

Claude Code

/plugin marketplace add FaireDose/CHEPTA
/plugin install chepta@chepta

Codex

$skill-installer install https://github.com/FaireDose/CHEPTA/tree/main/ai/skills/chepta

Any other assistant (no skills)

Put this line in its custom instructions, project instructions, custom GPT or Gem, so it applies to every chat:

For chemical-engineering calculations, read https://fairedose.github.io/CHEPTA/use.md and follow it.

Menu names change between app versions; if you can't find them, search your assistant's help pages for "skills". More: ai/README.md · Live workbench · Source
