**How to help:** pick a pair, ask your AI assistant to find open experimental data for it
(prompt "Find open data for a pair" in [ai/START_PROMPTS.md](../ai/START_PROMPTS.md); rules in
[AGENTS.md](../AGENTS.md)), and submit it with the
[Data](https://github.com/FaireDose/Fugacity/issues/new?template=ai-contribution.yml) form.
Put the pair in the issue title so others can see it is taken.
Some pairs are only partly miscible (for example water with benzene, toluene or
chloroform); liquid-liquid data for them is welcome too.
